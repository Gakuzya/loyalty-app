# ☕ LoyaltyHub — Облачная система лояльности (цифровые штампы)

> Современная замена бумажных карточек лояльности для локальных кофеен и пекарен. Клиенты копят штампы по QR-коду, бариста начисляет бонусы за секунду, а владельцы получают детальную аналитику и графики посещаемости.

---

## 🚀 Архитектура и функционал

### 1. 📱 Клиентская часть (Mobile-First) — `/card/[slug]`
- **Интерактивная карточка 6 штампов**: тактильные круглые ячейки с анимациями появления через `framer-motion`.
- **Эффект праздника**: анимационный салют конфетти (`canvas-confetti`) при получении 6-го подарочного напитка.
- **Личный QR-код гостя**: сгенерирован через `qrcode.react`, готов для считывания на кассе.
- **Индикатор прогресса**: процент заполнения карточки и подсказка о следующем подарке.

### 2. 🤳 Терминал Бариста — `/scan` и `/action/[qrToken]`
- **Полноэкранный сканер**: камера на базе библиотеки `html5-qrcode` со стильным видоискателем и лазерной сеткой.
- **Мгновенное начисление**: кнопка «+1 Штамп» в один клик.
- **Списание подарков**: безопасное списание бесплатного кофе при наличии доступных наград на балансе гостя.
- **Аудит транзакций**: каждое действие фиксируется в базе данных с точным временем.

### 3. 📊 Панель Владельца — `/dashboard`
- **Ключевые KPI**: общее число выданных штампов, выпитых бесплатных напитков, база постоянных гостей и % возвращаемости (Retention).
- **Почасовой график пиков**: наглядный BarChart на `recharts` с автоподсветкой часов максимальной загрузки кофейни.
- **Рейтинг постоянных гостей**: топ клиентов по количеству визитов.
- **Журнал операций live**: аудит всех начислений и списаний в реальном времени.

## 🛠 Технологический стек

- **Фреймворк:** [Next.js 16 (App Router)](https://nextjs.org/) + React 19 + TypeScript
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
- **База данных:** [Supabase](https://supabase.com/) (PostgreSQL)
- **ORM:** [Prisma ORM](https://www.prisma.io/)
- **Анимации:** [Framer Motion](https://www.framer.com/motion/) + Canvas Confetti
- **QR-коды:** `html5-qrcode` (сканер) + `qrcode.react` (генератор)
- **Графика и иконки:** [Lucide React](https://lucide.dev/) + [Recharts](https://recharts.org/)

## ⚡ Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Gakuzya/loyalty-app.git
cd loyalty-app
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните реквизиты вашего проекта в `.env`:
- `DATABASE_URL` — строка подключения через Transaction Pooler Supabase (порт 6543)
- `DIRECT_URL` — прямое подключение для миграций (порт 5432)
- `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` — API ключи из Supabase Dashboard

### 4. Синхронизация схемы БД
```bash
npx prisma db push
npx prisma generate
```

### 5. Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.
